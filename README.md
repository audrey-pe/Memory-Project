# Memory Project

## Présentation

**Memory Project** est un jeu de mémoire développé en HTML, CSS et JavaScript dans le cadre de ma formation à l’ENI École Informatique.

Le but du jeu est de retrouver les paires de cartes identiques en faisant appel à sa mémoire visuelle.

## Technologies utilisées

- **HTML** : structure de la page.
- **CSS** : mise en forme et interface du jeu.
- **JavaScript** : gestion de la logique du jeu et des interactions.

## Installation

Cloner le dépôt Git :

```bash
git clone https://github.com/audrey-pe/Memory-Project.git
```

Ouvrir le fichier `index.html` dans un navigateur pour lancer le jeu.
